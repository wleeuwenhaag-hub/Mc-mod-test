# AuraFX — extracted JAR contents

This archive contains the files extracted from `AuraFX-1.0.0+mc1.21.11.jar`.

## Important

This is **not the original source project**. The `dev/aurafx/**/*.class` files are compiled Java bytecode. The archive does not contain the original Java source files, Gradle build scripts, or development resources needed to rebuild the mod normally.

You can upload these extracted files to GitHub for inspection or archival. To properly develop and rebuild AuraFX, the original source project is still needed (for example, `src/main/java`, `src/main/resources`, and Gradle files).
